# Project Template

This repository contains a **project template** designed to serve as a reusable starting point for all future projects.  
It provides a standard folder structure and base documentation to ensure consistency and best practices across teams.

---

## 📁 Structure

- `constitution/` – Core principles or high-level goals of the project
- `plan/` – Planning documents or roadmap
- `spec/` – Specifications and technical details
- `tasks/` – Task breakdowns or execution items
